        HONEST LIMITS
        1,000,000 dots are still superparticles, not a resolved Milky Way. Gas is collisionless bookkeeping, not SPH. Lifetimes are a mass–age clock, not stellar-evolution tracks; lifecycle speed ≠ 1 is never calibrated. The default galaxy is an exploratory warm disk in a live halo, not a calibrated equilibrium model, and a short run does not prove long-term stability. Encounters are collisionless. Barnes–Hut with several dense concentrations is coarser than an isolated galaxy. Wall-time estimates scale from one measured 100,000-particle, 10-thread point; node estimates multiply that by one measured speed factor per node. θ and softening are not in the timing model. The worker stops at 120 h of wall time per resume window. Closing the lid sleeps the Mac; runs on an always-on node continue and sync when the Mac wakes.

        COMPUTE NODES
        Where the physics runs.
        This Mac is the hub: it keeps every frame and the library. Nodes are reached over SSH with this Mac's key (Tailscale addresses work). If a node rejects the key, enter its password once on its card: it installs this Mac's key and is never stored.
